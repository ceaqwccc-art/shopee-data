# shopee-data

Shopee 电商数据  `x-sap-ri` 签名生成与接口集成

面向 Shopee 电商数据、接口对接和业务分析场景，提供商品、店铺及批量商品数据，Shopee 接口签名参数生成。

### 店铺推荐商品

支持店铺商品及推荐商品数据获取，适用于：

- 店铺商品列表分析
- 店铺热销商品筛选
- 类目和商品结构分析
- 店铺竞品及选品研究

### 商品详情

支持提交店铺 ID 与商品 ID，获取商品详情，适用于：

- 商品池批量更新
- 竞品价格监控
- SKU 和库存同步
- 商品数据清洗与入库

### 关键词与类目搜索

支持按关键词、类目及搜索条件获取商品列表数据，适用于：

- 关键词商品检索
- 类目商品采集
- 热销商品与选品分析
- 搜索排名和竞品监控

### `x-sap-ri` 签名生成

Shopee 接口签名参数生成：

- `x-sap-ri` 相关签名参数生成
- 请求参数及请求体签名
- 多国家/地区包名适配
- 设备随机
